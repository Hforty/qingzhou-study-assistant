# 轻舟学习助手 Android 1.1.0 候选版

面向计算机考研的本机学习规划与记录工具。包含数学一／二、英语一／二、408 和政治三档安排。桌面软件与微信小程序不受本项目影响，也不会自动导入它们的记录。

## 功能

- 首次选科后生成自然周计划；直接编辑，不提供草案。
- 任务右滑完成或撤销，计划页长按编辑；单点顺延、整门课程顺延和永久暂停。
- 漏学任务顺延；重新安排保留人工修改；原版内恢复默认。
- 每日预算、学习日、考试规划日期与政治安排共用设置。
- 25／50／90 分钟专注，暂停、继续、提前结束；原生前台服务显示计时通知。
- 各课程今日专注时长，完整任务与专注历史、课程和日期筛选。
- 知识点掌握标记独立于任务打卡；科目默认收起，搜索时展开匹配项。
- Android 文件选择器导入／导出完整 JSON 备份，统一 30 MiB 限制。
- 默认日期最早 2027-12-20，过期自动滚动；手动日期不会覆盖。
- 课程顺延、重新安排和恢复默认展示影响摘要；上次人为调整可撤销，保留期间新增的完成记录。
- 知识点标记“需要再看”，填写原因与回顾日期；回顾不重复生成，受学习日、预算和政治配额约束。
- 按周查看课程投入、任务完成与未完成原因；支持标注来源的手动补记。
- 自动保留最近5份有效恢复点，支持损坏记录恢复；完整备份不嵌套打包恢复点。
- 今日任务优先、过去日期收纳、科目和章节组织、系统深浅色与减少动画支持。
- 原生4×2桌面小组件，展示下一任务并返回共享计时。

## 实现

Java Activity + 系统 WebView + AndroidX WebKit 本地资源加载器。页面、课程目录与 JS 引擎全部包含在 APK 中；无需浏览器或单独的源文件。应用没有 INTERNET 权限，外部邮件及版本链接交给系统客户端。

`web/lib/qz` 保留小程序的目录和知识点 ID，并在安卓版内修正预算计算、顺延占位、暂停恢复顺序和默认计划恢复。没有修改小程序源码。

记录键继续为 `qingzhou.android.v1`，格式升至schemaVersion 2，保留旧版有效数据与v1备份读取。增加按周默认计划和历史总结、薄弱回顾、手动专注来源、最多100条必要调整摘要及一次可撤销差异，不存储完整事件重播。

原生读写返回非空JSON响应，修复首次启动的空值转换问题；写入使用共享锁、冲突检查及回读，成功后才更新界面。通过原生修订号避免每秒传输完整学习历史。

`FocusController`统一应用、通知和组件的计时；失败结束结果通过AtomicFile保留，重试按专注ID去重。`RecoveryStore`只保留通过校验的恢复点。恢复点在应用私有目录，完整备份通过系统文件选择器另存。

界面按稳定ID局部更新，秒级计时只更新数字。所有代码和课程内容均在APK内，安装不需要源码或额外启动文件。

## 构建

需求：JDK 21、Gradle 9.6.0、Android SDK Platform 36、Build Tools 36.0.0。最低 Android 8.0 / API 26，目标 API 36。

本次复用2026-10-18工作区的便携工具，依赖缓存复制在新日期目录中。执行 `构建.ps1 -Task all` 离线生成候选、调试和原生验收包；也支持单独assembleRelease。未下载新依赖。其他环境通过 `QINGZHOU_ANDROID_TOOLS_ROOT` 指定工具工作区，或配置同版本Gradle与SDK构建。

签名通过环境变量 `QINGZHOU_RELEASE_CONFIG` 指向源码目录之外的私有JSON配置（不要提交仓库）：

```json
{"storeFile":"你的私有密钥绝对路径","storePassword":"私有密码","keyAlias":"qingzhou","keyPassword":"私有密码"}
```

发布后的覆盖安装必须保持 `cn.qingzhou.study` 包名、相同签名及递增 versionCode。密钥不在源码、APK 源码资产或 GitHub 仓库中。

## 验证

`node --test tests/*.test.mjs` 检查计划、日期、计时与事务。`node tests/browser-check.mjs` 使用 Windows 已安装的 Edge 做移动视口点击与触摸验收；它不是 Android 真机测试。

当前70项核心测试及22组移动界面检查通过，覆盖320px小屏、大字体、深色及减少动画。它们不能代替实际Android运行验收。

`app/src/androidTest`包含基于Android SDK自定义Instrumentation的7组真实WebView检查，无模拟原生桥接，也不增加测试框架依赖。通过独立 `.debug` 包运行，不修改正式版记录。验收包已构建，尚未在手机安装执行；安装之前需明确同意。

Redmi K70 Pro正式包覆盖安装、通知、系统返回、文件选择、桌面组件和锁屏仍待真机确认，因此1.1.0暂标候选预发布，不宣称稳定版。系统强制停止或重启可能停止服务，返回应用时按时间戳核对。
