# 轻舟学习助手 Android 1.0.0

面向计算机考研的本机学习规划与记录工具。包含数学一／二、英语一／二、408 和政治三档安排。桌面软件与微信小程序不受本项目影响，也不会自动导入它们的记录。

## 功能

- 首次选科后生成自然周计划；直接编辑，不提供草案。
- 任务右滑完成或撤销，计划页长按编辑；单点顺延、整门课程顺延和永久暂停。
- 漏学任务顺延；重新安排保留人工修改；原版内恢复默认。
- 每日预算、学习日、考试规划日期与政治安排共用设置。
- 25／50／90 分钟专注，暂停、继续、提前结束；原生前台服务显示计时通知。
- 各课程今日专注时长，完整任务与专注历史、课程和日期筛选。
- 知识点掌握标记独立于任务打卡；科目默认收起，搜索时展开匹配项。
- Android 文件选择器导入／导出完整 JSON 备份，统一 30 MiB 限制。
- 默认日期最早 2027-12-20，过期自动滚动；手动日期不会覆盖。

## 实现

Java Activity + 系统 WebView + AndroidX WebKit 本地资源加载器。页面、课程目录与 JS 引擎全部包含在 APK 中；无需浏览器或单独的源文件。应用没有 INTERNET 权限，外部邮件及版本链接交给系统客户端。

`web/lib/qz` 保留小程序的目录和知识点 ID，并在安卓版内修正预算计算、顺延占位、暂停恢复顺序和默认计划恢复。没有修改小程序源码。

记录存于应用私有 SharedPreferences，通过原生接口校验、比较当前版本、写入和回读。界面只在保存成功后更新。计时服务与界面共享事务锁；专注 ID 用于避免重复记账。

## 构建

需求：JDK 21、Gradle 9.6.0、Android SDK Platform 36、Build Tools 36.0.0。最低 Android 8.0 / API 26，目标 API 36。

本次日期工作区已配置便携工具，在此文件夹执行 `构建.ps1 -Task assembleRelease`。脚本将构建缓存及输出限定在父工作区。其他环境可用同版本 Gradle 执行 `assembleRelease`，自行配置 SDK 路径。

签名通过环境变量 `QINGZHOU_RELEASE_CONFIG` 指向工作区外的 JSON 配置（不要提交仓库）：

```json
{"storeFile":"你的私有密钥绝对路径","storePassword":"私有密码","keyAlias":"qingzhou","keyPassword":"私有密码"}
```

发布后的覆盖安装必须保持 `cn.qingzhou.study` 包名、相同签名及递增 versionCode。密钥不在源码、APK 源码资产或 GitHub 仓库中。

## 验证

`node --test tests/*.test.mjs` 检查计划、日期、计时与事务。`node tests/browser-check.mjs` 使用 Windows 已安装的 Edge 做移动视口点击与触摸验收；它不是 Android 真机测试。

当前自动化覆盖 34 项核心测试与 9 组界面检查。Redmi K70 Pro 的安装、系统返回、文件选择、通知、锁屏及 HyperOS 后台行为仍需真机验证，因此首次交付标为预览版。系统强制停止、重启或省电策略可能停止服务；重新打开会按时间戳核对，不承诺锁屏后准时提醒。
