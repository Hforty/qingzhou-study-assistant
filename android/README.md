# 轻舟学习助手 Android 1.2.0 候选版

面向考研的本机学习计划、清单与专注记录工具。支持数学一／二、英语一／二、408和政治三档。桌面软件及微信小程序未修改。

## 本版新增

- 手机系统通知：固定学习时间、指定重复星期或跟随学习日；单个学习任务与日常待办可设置时间。
- 通知可打开清单、开始对应任务专注，或10分钟后再提醒。任务改期跟随新日期，完成、暂停及删除后取消；待安排的学习任务不提醒。
- 清单提供今天、全部待办、已完成；学习任务与自然周计划共用记录。普通待办只需标题，可选日期和提醒，不占学习预算。
- 25／50／90分钟及1–240分钟自定义倒计时，正计时最长单轮24小时，1–120分钟休息倒计时。
- 专注记录保留具体任务、当时标题与考试类型；暂停和休息不计入学习时长，结束不会自动完成任务或开始下一轮。
- 专注首屏直接开始，课程和时长收纳；系统深浅色、减少动画和小屏大字体适配。
- 保留原有课程顺序、漏学顺延、永久暂停、原版恢复、掌握自评、薄弱回顾、周总结、手动补记、桌面组件及最近5份自动恢复点。

## 通知与计时实现

Java原生Activity、系统WebView和AndroidX WebKit本地资源加载器。APK包含所有页面和课程；没有INTERNET权限。外部邮件与版本链接交给系统客户端。

ReminderManager共用一个系统AlarmManager待触发事件，计算下一条固定提醒、任务提醒、稍后提醒及计时结束。普通通知无需长期轮询服务；只有用户开启专注或休息计时时使用前台服务。重复事件标识和稍后提醒保存在应用私有记录中，反复打开不会重复生成通知。

首次保存提醒或开始原生计时会按需请求通知权限。未允许通知仍可保存和使用计划、清单及计时。声音、振动和免打扰遵循用户系统通知设置。可选的“准时提醒”跳转Android准确闹钟授权页；未授权时退回普通系统调度，可能延迟。没有全屏提醒权限，也不调用系统时钟创建响铃闹钟。

接收正常开机、升级、时间与时区变化后重新安排。被系统强行停止后需重新打开应用；HyperOS后台限制与锁屏效果仍需实际手机核对，不能承诺所有系统状态准时通知。

FocusController共用原生状态处理页面、通知和组件操作；以同次开机的单调时间核对运行时长，旧计时与重启后回退时间戳。结束结果先冻结到AtomicFile，再按ID去重保存；失败重试不改变原日期和时长。休息只保存结束结果，不产生学习时长。

## 数据与覆盖安装

包名继续为cn.qingzhou.study，versionName 1.2.0，versionCode 4。正式签名保持不变，可覆盖安装1.1.0或1.0.1，不需卸载、清除数据或手动备份。

沿用qingzhou.android.v1记录键与可扩展的schemaVersion 2。旧版缺少todos、reminders、taskReminders、lastFocusResult时补默认字段，原学习事实保持。升级前及重要替换前保留有效恢复点。完整备份仍接受v1／v2，导入导出统一30 MiB限制。损坏记录进入恢复页面，不创建空白覆盖。

## 构建

最低Android 8.0／API26，targetSdk36。使用JDK21、Gradle9.6.0、Android SDK Platform36和Build Tools36.0.0。没有新增依赖或工具下载。

本次复用工作区2026-10-18的便携工具和已有离线缓存。可通过QINGZHOU_ANDROID_TOOLS_ROOT覆盖工具根目录。私有签名配置由QINGZHOU_RELEASE_CONFIG指向源码之外的文件；不要上传密钥、密码或学习记录。

```powershell
.\构建.ps1 -Task all
```

all离线生成正式签名候选APK、独立.debug包及原生验收包。手机只需正式候选APK，不需要源码和缓存。
