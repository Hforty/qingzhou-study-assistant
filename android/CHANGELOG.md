# Android 1.0.1 · 2026-10-18

修复首次安装启动时显示 `"undefined" is not valid JSON`、误入记录恢复页的问题。原因是 WebView 将 Java `String null` 返回值转换为 JavaScript `undefined`；新版以非空 JSON 响应明确表示记录是否存在。

读取接口异常不会当作新用户覆盖数据；原始损坏内容仍可导出。增加首次启动、保存后重开、旧记录保留、异常响应与失败写入测试。

沿用包名、签名和记录键，内部 versionCode 升至 2，可直接覆盖安装 1.0.0，无需卸载或清除数据。

# Android 1.0.0 · 2026-10-18

首个 Android 预览版。提供首次选科、直接编辑周计划、右滑打卡、长按编辑、课程顺延与暂停、番茄钟、掌握进度及学习历史。本机存储，支持完整备份。

相对共用目录的旧计划实现，修正顺延时的重复占位、完成时间不计入预算、部分课程长期排不到、恢复暂停顺序影响安排、编辑后的完成状态错误套入原版，以及更改学习日后默认计划混入人工标题的问题。

界面采用浅绿工作台，五个底栏入口；课程进度默认折叠，支持完整知识点搜索与选择。设置保存保留当前页面，失败保留输入；专注结束保存失败冻结结果供重试。

使用独立 Android 记录；不自动迁移桌面或小程序数据。APK 已签名，后续更新需保留原签名并提高内部版本号。
